# build/ data files

This directory is gitignored (regenerated by CMake) but the CSVs in it are
real collected/measured data, not build output — kept here because that's
where every program in this project reads/writes them by default (relative
to the working directory the `.exe`s are run from).

Historical/superseded files have been moved to `archive/` — see below.

## Active files (currently referenced by scripts or in ongoing use)

**Raw hand-posed tick recordings** (source data — arm physically posed by hand, torque off):
- `recorded_hand_poses (1).csv`, `(2).csv`, `(3).csv` — three batches of general hand-posed configurations, collected via `record_hand_poses.exe`. Extracted into `TARGET_POSES` in `tests/test_five_pose_ndi_capture.cpp` (indices 483-656 and 657-856; see `CLAUDE.md`'s kinematic-calibration section for exactly which rows).
- `recorded_hand_poses_fixed_elbow_yaw.csv` — same idea, but `elbow_yaw` (motor 4) locked at its calibrated midpoint (2095) for the whole session; only the other 6 joints hand-posed. Collected via `record_hand_poses_fixed_elbow_yaw.exe`. Extracted into `TARGET_POSES` indices 857-1238.

**NDI-captured calibration datasets** (produced by `test_five_pose_ndi_capture.exe --quick-test`, reading the tick targets above):
- `quick_calibration_test.csv` — 218 poses (129 "realm-restricted" + 89 of a 174-pose widened-range batch; that collection run was interrupted and never resumed).
- `quick_calibration_test_batch3.csv` — 197 poses, isolated capture of the batch-3 hand poses only.
- `quick_calibration_test_fixed_elbow_yaw.csv` — 374 poses, the elbow_yaw-locked dataset. **Currently the best-performing dataset in the project** (blocked-CV RMS 0.78mm, physically validated at ~2.86mm mean / 3.35mm RMS — see `CLAUDE.md`).

**Validation tool inputs/outputs** (`test_five_pose_ndi_capture.exe --validate`, see `CLAUDE.md`'s kinematic-calibration section for what this tests and why it's different from the datasets above):
- `validation_ticks.csv`, `validation_ticks_fixed_elbow_yaw.csv` — input tick targets (genuinely new points, not in any fit dataset).
- `validation_points.csv`, `validation_points_combined415.csv`, `validation_points_fixed_elbow_yaw.csv`, `validation_points_fixed_elbow_yaw_gp.csv` — the above with predicted positions added (by `calibration/current/gen_validation_predictions.py` or `gen_validation_predictions_gp.py`), ready to feed to `--validate`.
- `validation_repeatability_test.csv`, `validation_repeatability_8points.csv` — same mechanism, repurposed to measure repeatability instead of accuracy (repeat visits to the same points; compare raw actual positions to each other, not to the predictions).
- `validation_results.csv` — output of the most recent `--validate` run (overwritten each time — copy it elsewhere first if you need to keep a specific run's results).

## `archive/`

- `archive/raw_hand_poses/` — superseded/incomplete hand-pose recordings and their auto-generated `TARGET_POSES` text snippets (`recorded_hand_poses_OLD*.csv`, the 100-pose batch, the realm-safe-filtered derivative, the multi-joint backlash survey, etc.).
- `archive/ndi_capture/` — superseded NDI-captured datasets from earlier in the project's history (287-pose set, backlash-margin comparison sets, IK-validation sets, motor-3-only sets, the old default-mode `five_pose_ndi_capture.csv`, `settling_diagnostic.csv`, etc.). Each is referenced by name somewhere in `CLAUDE.md`'s history if you need to know what a specific one was for.
